# シェルスクリプト作成規約

シェルスクリプト（`*.sh`）を作成・編集する際の規約。コマンド実行の方針は [shell-operations.md](shell-operations.md) に従う。

## 1. スクリプトの出力方針

スクリプトの種別により、出力ポリシーを使い分ける。

### 1.1. ユーザー実行スクリプト

ユーザーが直接実行するスクリプトは、全ての出力を画面表示する。
ユーザーが判断・確認できるように詳細情報を提示する。

- **全て画面出力**: 実行結果の全体像、エラー詳細、確認プロンプトなど
- **対話的**: 不可逆操作の直前にユーザーへ確認を取る

### 1.2. AI 実行スクリプト

AI が実行するスクリプトは、AI のトークン消費を抑える。

- **標準出力の抑制**: エラー以外の標準出力は、AI が判断に使う情報（差分サマリ等）を除き出力しない
- **エラーは stderr へ**: エラーメッセージは `>&2` で stderr に出力し、`exit 1` で終了する
- **正常完了時**: 完了を示す1行のみ出力する（例: `✅ 完了しました。`）

## 2. コマンド出力の捕捉パターン（AI 実行スクリプト向け）

コマンドが失敗した場合のみ出力を表示する。

```bash
LOG=$(mktemp)
if ! some_command > "$LOG" 2>&1; then
    cat "$LOG" >&2
    rm -f "$LOG"
    exit 1
fi
rm -f "$LOG"
```

成功時に差分など確認用の情報を出力する場合は、`grep` 等で必要な行のみを抽出して出力する。

## 3. スクリプト作成時の共通ルール

- `set -e` を先頭に記述し、エラー時に即終了させる
- 静音フラグ（`-q`）があるコマンドは積極的に使用する
- 標準出力が不要なコマンドは `> /dev/null 2>&1` でリダイレクトする
- 機密情報（パスワード、トークン）を標準出力・ログに出力しない（[security.md](security.md) 参照）

## 4. 実行権限

- `scripts/` 配下の `.sh` ファイルは実行権限（`+x`）を付与した状態でコミットする
- `Write` / `Edit` 後の hook（[shell-operations.md](shell-operations.md) 4章）が `scripts/` 配下の `.sh` に `+x` を自動付与するため、
  AI が明示的に `chmod +x` コマンドを実行する必要はない
